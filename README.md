# 04 · Serverless Framework

festival-control/ contiene el recorrido guiado de los bloques 01–09: API de eventos con Serverless y app Expo que la consume.
venue-control/ es el entrenamiento evaluable: API CRUD de zonas en /zones y app React Native para gestionarlas.
Las dos APIs están desplegadas en AWS (us-east-1, stage dev) con Lambda y API Gateway.
El README de venue-control/ explica la arquitectura, la ejecución en local, el despliegue en AWS y las decisiones tomadas.
